Amazon Saved for Later export

A bookmark that saves the Saved for Later list under your Amazon cart as a JSON file. It runs in your browser, on the page you already have open, and sends nothing anywhere.

Install

Drag this button to your bookmarks bar. Can't see the bar? Press Ctrl+Shift+B (⌘+Shift+B on a Mac).

Saved for Later → JSON

Can't drag? Create a new bookmark and paste the contents of bookmarklet.txt as its URL. On a phone, bookmarklets are awkward at best; this is meant for a desktop browser.

Use

  1. Open your Amazon cart while logged in.
  2. Click the bookmark. It scrolls through Saved for Later until every item has loaded.
  3. When it says Found N items, click Download file. You get amazon-saved-for-later-YYYY-MM-DD.json.

What's in the file

{
  "format": "amazon-saved-for-later",
  "version": 2,
  "exportedAt": "2026-01-15T18:30:00.000Z",
  "store": "www.amazon.com",
  "items": [
    {
      "asin": "B0ABCDEFGH",
      "title": "Product title as shown in the cart",
      "price": "$19.99",
      "priceValue": 19.99,
      "images": ["https://m.media-amazon.com/images/I/…jpg", "…"]
    }
  ]
}

Every field is described in FORMAT.md, including the quirks of Amazon's picture URLs.

Privacy

  • No network requests. The bookmark reads the page and builds the file in your browser. Nothing is uploaded, and there is no server.
  • No permissions. It isn't an extension. It runs only when you click it, and only on Amazon's own storefront addresses.
  • Read it first. A bookmarklet runs with the same access as the page it runs on, so read the source before installing any of them. This one is src/bookmarklet.js, and the button above is built from it automatically on every change.

Limits

  • It reads Amazon's page layout, which changes without notice. If it finds no items, open an issue.
  • Tested on amazon.com. Other Amazon stores are accepted and should work, but are untested.
  • Prices are what the cart showed at export time.
